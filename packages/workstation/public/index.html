SPEC REPOSITORY

規格庫結構

spec/REQ/feature/Gherkin · 系統設計
tests/REQ/feature/Steps · Hooks · Fixtures
reports/REQ/feature/run/報告 · 截圖 · Trace
projects/<project>/產品 Git submodule

Spec commit 固定規格、測試與產品版本；報告 commit 另行保存執行證據。

測試依賴

只執行固定的 npm install／ci --ignore-scripts。初次安裝產生的 lockfile 需要明確提交。

驗收環境

從這個 Spec Repo 的固定產品版本啟動服務，不使用來源不明的既有網站。

健康檢查必須回傳固定版本的 commit。設定變動會讓測試確認失效。
